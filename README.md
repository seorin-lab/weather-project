# weather-project

기상청 ASOS(종관기상관측) 일자료를 공공데이터포털 API로 받아서 PostgreSQL에 쌓고, 데이터에 빠진 값이나 이상한 값이 없는지 확인한 다음 폭염일수 같은 이상기후 지표를 계산해 보기 위해 만든 프로젝트입니다.

데이터 관리 쪽(데이터 엔지니어, DBA, 데이터 거버넌스) 진로를 준비하고 있는데, 분석 결과만 보는 것보다 데이터를 받아 오고 저장하고 점검하는 과정을 직접 해 보고 싶어서 시작했습니다.

## 환경

- Python 3.12 (requests, python-dotenv)
- PostgreSQL 18 (Postgres.app), DBeaver
- macOS (M2), VS Code, Git

## 데이터

- 출처: 공공데이터포털 [기상청 지상(종관, ASOS) 일자료 조회서비스](https://www.data.go.kr)
- 관측소별로 하루 단위 기온, 강수량, 습도 등을 JSON으로 받을 수 있습니다.

## 해 보면서 알게 된 것

**강수량이 빈 값인 날과 0.0인 날이 따로 있었다**

결과를 보다가 강수량이 `0`으로 나온 날과 `0.0`으로 나온 날이 섞여 있는 걸 봤습니다. 확인해 보니 `0`은 API가 빈 값을 줘서 제 코드가 0으로 바꿔 찍은 것이었고, `0.0`은 API가 실제로 준 값이었습니다. 화면에 보여 줄 때는 상관없지만, 이대로 DB에 넣으면 서로 다른 두 경우가 구분되지 않습니다.

두 값이 정확히 무슨 뜻인지는 기상청 활용가이드에서 확인해 볼 생각이고, DB에 넣을 때는 빈 값을 0이 아니라 NULL로 저장하려고 합니다.

**인증키를 그대로 넣으면 오류가 날 수 있다**

공공데이터포털 인증키는 인코딩된 키와 원래 키 두 가지가 있습니다. requests는 요청을 보낼 때 알아서 인코딩을 하기 때문에, 인코딩된 키를 넣으면 한 번 더 인코딩되어 오류가 날 수 있습니다. 그래서 `urllib.parse.unquote`로 키를 원래 형태로 바꾼 뒤 쓰도록 했습니다.
